THE PROCESS

Make one good clip.
Then make it repeatable.

01

Give your character a reason to exist.

Start with a role, an audience and one useful promise. A memorable face helps. A reason to watch helps more.
+
  • Choose one audience, not everyone.
  • Describe the practical result viewers should get.
  • Keep a short identity note you can reuse.
Character brief
02
Build a face you can keep.
Make one strong portrait first. Then use it as an image reference for every new angle. A text description alone is not an identity lock.
+
  • Approve the first face before expanding it.
  • Compare the nose, jaw, hairline and any facial hair.
  • Generate production shots separately at full resolution.
Identity reference sheet
03
Find the voice before the motion.
Choose a voice, test the exact line, and keep that voice consistent. If your tool accepts audio, animate to the recording you actually approved.
+
  • Read the line aloud before generating video.
  • Shorten the script if words blur together.
  • Save the actual voice choice or reference audio.
Voice + script direction
04
Make the body believe the words.
One useful thought. One clear gesture. A camera move that supports both. Five seconds should feel like a real moment, not a checklist of movements.
+
  • Use one main action, not five competing instructions.
  • Let the gesture finish naturally.
  • Avoid a large pullback that invents the rest of the room.
Five-second talking shot
05
Cut clean. Explain visually.
Alternate useful angles at the edit. Add a few words that clarify the point, rather than repeating every spoken word on screen.
+
  • Keep the room fixed while camera angles change.
  • Make every line point to a real object.
  • Use readable holds, not constant motion.
Edit + graphics brief
06
Test one clip. Then build the batch.
Look for the failures that still images can hide: drifting faces, unclear speech, frozen hands and backgrounds that quietly rearrange themselves.
+
  • Watch once for speech, once for motion.
  • Inspect a run of frames around gestures and cuts.
  • Fix the test before spending time on a whole series.

Which tools should I use?
You need an image generator that accepts reference images, a voice tool or a recorded voice, an image-to-video or lip-sync tool with the controls you need, and an editor. Check each tool’s actual capabilities and output rights. This guide’s prompts are adaptable instructions, not a promise that every model supports every feature.
Can I change the location?
Yes. Keep the character identity and voice; create a new scene description. Within that scene, lock the furniture, light direction, microphone mount and a few background anchors before changing camera angles.
How much dialogue fits?
Try one concise useful idea. Start with a short sentence, read it in the chosen voice and shorten it if articulation suffers. Technical words need breathing room. There is no universal word count that guarantees a natural five-second clip.
Do I need full subtitles?
Use readable keyword graphics when they carry the idea well. A separate caption track can support accessibility without adding a second layer of burned-in text. Choose captions based on the audience and publishing format.
